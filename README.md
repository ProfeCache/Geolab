# ◇ GeoLab — Laboratorio visual de geometría

**La geometría, en tus manos.** GeoLab es un explorador interactivo para aprender geometría mirando y tocando: cuerpos en 3D que se pueden girar, figuras planas para analizar y desarrollos que se arman y desarman en pantalla.

Creado por **Lautaro Micucci**.

---

## ✨ Qué se puede hacer

### Cuerpos 3D
Girá, acercá y explorá cada cuerpo. Tocá sus **caras**, **aristas** y **vértices** para conocer el nombre y la función de cada parte. Se puede activar la vista de partes ocultas.

- **Poliedros regulares:** cubo, tetraedro, octaedro, dodecaedro, icosaedro
- **Prismas:** triangular, rectangular, pentagonal
- **Pirámides:** cuadrangular, troncos de pirámide y bipirámides
- **Cuerpos redondos:** cilindro, cono, esfera

### Figuras 2D
Explorá **lados**, **ángulos**, **vértices** y **diagonales** de:

- **Triángulos:** equilátero, isósceles, escaleno, rectángulo
- **Cuadriláteros:** cuadrado, rectángulo, rombo, romboide, trapecio, trapezoide

### Desarrollos planos
Elegí un cuerpo y mirá cómo se **abre y se cierra** su desarrollo con un control deslizante. Un mismo cuerpo puede tener varios desarrollos posibles (**Otro desarrollo ↻**).

### Para aprender y conversar
- Datos del conjunto: cantidad de caras, aristas y vértices (ideal para descubrir la relación de **Euler**).
- Una pregunta disparadora en cada forma, pensada para conversar en clase.
- Selección de partes por nombre, como alternativa accesible al toque.

## 🚀 Cómo usarlo

No hace falta instalar nada: GeoLab es un único archivo HTML, sin dependencias externas.

1. Descargá o cloná el repositorio:
   ```bash
   git clone https://github.com/ProfeCache/Geolab.git
   ```
2. Abrí `index.html` en cualquier navegador moderno.

También se puede publicar tal cual con **GitHub Pages** (el archivo ya se llama `index.html`).

### Controles
| Acción | Cómo |
|---|---|
| Girar el modelo | Arrastrar con el mouse o el dedo, o usar ↶ ↑ ↷ |
| Acercar / alejar | Botones **+** y **−** |
| Conocer una parte | Tocarla en el modelo |
| Volver al inicio | **↺ Restablecer** |

Funciona en computadoras, tablets y celulares.
